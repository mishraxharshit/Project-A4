# Research

This directory holds papers, literature reviews, experiment logs, and research notes for Project-A4.

## Suggested Structure

```
research/
├── papers/          # Full write-ups (drafts and finished)
├── notes/           # Working notes, literature reviews
├── experiments/     # Experiment logs, configs, and results
└── data/            # Small reference datasets (large data should not be committed directly — see .gitignore)
```

## Conventions

- Prefix files with the date (`YYYY-MM-DD-title.md`) or a clear version marker.
- State status at the top of each document: `Draft`, `In Review`, or `Final`.
- Cite external sources; do not paste copyrighted material verbatim.
- Large datasets belong in external storage with a pointer/README here, not committed directly to Git.

See the top-level [CONTRIBUTING.md](../CONTRIBUTING.md) for the full contribution standards.
