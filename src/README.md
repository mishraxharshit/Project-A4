# Source

Core reference implementations and libraries for Project-A4 will live here.

The primary language/stack has not been finalized yet — see [`docs/ARCHITECTURE.md`](../docs/ARCHITECTURE.md) for open decisions. Once chosen, this directory will include:

- Package/module structure appropriate to the chosen language
- A build/dependency manifest (e.g., `pyproject.toml`, `package.json`)
- Inline documentation and type annotations where applicable

All code contributions should include corresponding tests under [`/tests`](../tests).
