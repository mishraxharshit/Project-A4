# Roadmap

This roadmap is intentionally lightweight at this stage. Update it as decisions are made and milestones are hit.

## Phase 0 — Foundation (current)

- [x] Repository scaffold: README, governance, contribution guides, security policy
- [x] Issue/PR templates and baseline CI
- [ ] Finalize primary tech stack for `/src`
- [ ] Publish initial `docs/ARCHITECTURE.md` decisions
- [ ] Open the repository publicly / announce to community

## Phase 1 — First Contributions

- [ ] Accept first external research contribution under `/research`
- [ ] Ship first reference implementation under `/src` with tests
- [ ] Set up a documentation site (if warranted) or expand `/docs`
- [ ] Establish a regular triage cadence for issues/PRs

## Phase 2 — Ecosystem Growth

- [ ] Define criteria for splitting a component into its own repository
- [ ] Publish first tagged release
- [ ] Formalize maintainer onboarding process
- [ ] Set up automated dependency/security scanning (e.g., Dependabot, CodeQL) once a stack is chosen

## Phase 3 — Sustainability

- [ ] Expand maintainer team
- [ ] Publish contribution/impact metrics
- [ ] Explore funding/sponsorship options if needed for infrastructure or research costs
